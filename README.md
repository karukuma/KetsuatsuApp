# 血圧記録アプリ

家庭で測った血圧を記録し、AIが傾向をまとめ、診察に持っていく1枚を印刷できるWebアプリです。
「Google Apps Script とスプレッドシート」で動きます。全部無料！

## なぜ作ったか

病院でもらえる紙の血圧手帳は、製薬会社のMRが配布するノベルティであることが多いようで、病院に行かないともらえない、ドラッグストアに行ってもあるかどうかわからない。という話を聞いたからです。

作るにあたっては、実際にもらった紙の血圧手帳を基準にしました。

---

## できること

### 記録する

- 起動すると自動でカーソルが入り、3桁入れると次の欄へ自動で移動
- 上下の値が逆なら警告
- 時間帯（朝・昼・夜）は測定時刻から自動判定
- 前回の値を上部に表示

### 続けたいと思えること

「楽しく続けてもらうこと」を優先しました

- 家庭目標をしたまわったら「演出と音が鳴ります」Base64で入れ替え可能（2段階）
- 「連続記録日数」と、目標までの残り日数を表示デフォルトでは100日
- 直近30日のうち何日が目安以下かを表示

### AIの活用（Gemini API）

- 血圧の傾向カード  直近の記録から2〜3文。3日ごとに更新
- 月次まとめ  終わった月ごとに1本。シートに蓄積し、過去の月も読み返せる
- Geminiさん教えて！質問コーナー 「土日と平日で違いはある？」など入力された基本情報をもとにGeminiさんが回答してくれます

### 診察にも！

- 直近1か月／3か月をA4にまとめて印刷できるようにPDFで保存ボタン
- 日ごとの表が主役。グラフも
- 目安を超えた値は太字、土日は色分けしました。週末の影響もばっちり

## 画面構成

| URL | 画面 | 見た目 |
|---|---|---|
| `.../exec` | 入力 | 明るい・シンプル |
| `.../exec?page=viewer` | グラフと傾向 | 黒地・派手 |
| `.../exec?page=report` | 月次まとめ・質問 | 黒地・派手 |
| `.../exec?page=print` | 印刷用 | 白地・表 |

読み手が違う画面は見た目も変えています。毎日使う画面は楽しく続けたくなるように、プリントは読みやすいように。

## セットアップ

詳細は [手入力版_セットアップ.md](手入力版_セットアップ.md) を参照してください。

1. スプレッドシートを新規作成し、URLからIDを控える
2. Google Apps Script で新規プロジェクトを作り、`.gs` と 4つのHTMLを貼る
3. ⚙ プロジェクトの設定 → スクリプト プロパティ に設定を入れる

   | プロパティ名 | 内容 |
   |---|---|
   | `SHEET_ID` | スプレッドシートのID |
   | `GEMINI_KEY` | [Google AI Studio](https://aistudio.google.com/apikey) で発行（無料） |

4. `checkSetup` を実行して設定を確認
5. ウェブアプリとしてデプロイ

APIキーとシートIDは**コードに書きません**。スクリプトプロパティに置くことで、
コードを貼り替えても設定が消えず、そのまま公開できます。

## ファイル構成

| ファイル | GASでの名前 | 役割 |
|---|---|---|
| `手入力版_コード.gs` | `コード.gs` | サーバー側の処理すべて |
| `手入力版_index.html` | `index` | 入力画面 |
| `手入力版_viewer.html` | `viewer` | グラフと傾向 |
| `手入力版_report.html` | `report` | 月次まとめ・質問 |
| `手入力版_print.html` | `print` | 印刷用 |

データはスプレッドシートの4枚のシートに入ります。

| シート | 内容 |
|---|---|
| `血圧記録` | 測定データ本体 |
| `月次まとめ` | AIが書いた月ごとの振り返り |
| `基本情報` | AIに毎回渡す前提（年齢・目標など）とキーワード設定 |

## 設計で決めたこと

### 楽しさ第一

良い数値のときだけ演出が出ます。悪い数値のときは何も起きません。

### 空白を許す

連続記録は3日までの空白を飛び越えて数えます。
登山や旅行に血圧計は持っていけません。「旅行に行くと記録が終わる」仕様は、
続ける仕掛けとして本末転倒です。

### メモ欄はAIに送らない

メモには体調や事情が書かれるため、本文はAIに渡しません。
代わりにキーワードに一致したかどうかだけを渡します。

```
メモ: 「筋トレ30分、風邪ぎみ」
AIへ: 運動: 筋トレ / 体調: 風邪
```

キーワードは `基本情報` シートで編集できます。

## 実装メモ

作る過程で踏んだ問題です。同じところで詰まる人がいるかもしれないので残します。

### `google.script.run` は、返せない値があると `null` を返す

戻り値に `Date` が混ざるとシリアライズに失敗し、例外ではなく `null` が成功ハンドラに渡ります。
`withFailureHandler` は呼ばれません。画面が「読み込み中…」のまま固まり、原因が分かりませんでした。

対策として、画面へ渡すのは文字列と数値だけに限定しています。

### スプレッドシートが `2026-07` を日付に変換する

月次まとめの重複判定に `2026-07` という文字列を使っていたところ、
シート側が日付として解釈し、読み出すと `Date` 型で返ってきました。
比較が毎回外れ、ページを開くたびに行が増えるという症状になりました。

セルの値は必ず正規化してから比較しています。

### 思考トークンの罠

Gemini 3系は既定で「思考」に多くのトークンを使い、それも `maxOutputTokens` に含まれます。
枠が足りないと本文が途中で切れます。`finishReason` が `MAX_TOKENS` のときは採用しないようにしています。

### Geminiさんは進化する

使えるモデル名を一覧表示する `listModels()` を用意しています。

### AIに曜日を渡さないと、カレンダーを推測させることになる

日付を 7/5 の形だけで渡していたとき、AIが「週末は血圧が高い」と答えたので不思議でした

曜日と測定時刻を明示的に渡すよう変更したところ、「日曜の夜は高いが、土曜はむしろ低い」と粒度が上がり、
挙げられた日付をカレンダーで確認できるようになりました。

## 動作環境

- Google アカウント（無料）
- Gemini API の無料枠（クレジットカード登録不要・1,500リクエスト/日）

AI機能を使わない場合、`GEMINI_KEY` は未設定のままで構いません。記録とグラフは動きます。
